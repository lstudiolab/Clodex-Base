# Clodex

Clodex is an experimental, source-first coding agent and language-model training system by Llab. Its implementation is written in Rust and C++.

The repository is being initialized with a resumable training pipeline, tokenizer, model runtime, checkpoint format, and guarded coding-agent tools. Model weights are not committed to Git history; checkpoints belong in external artifact storage or GitHub Releases.

See `docs/architecture.md` for the implementation plan and current capability boundaries.
