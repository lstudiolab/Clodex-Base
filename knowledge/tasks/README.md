# Task Memory

Store one Markdown file per substantial coding task. Do not save secrets, access tokens, private user data, or unreviewed conversation dumps.

Suggested format:

- **Goal:** what was requested.
- **Repository state:** relevant commit and files.
- **Changes:** what was actually changed.
- **Verification:** exact commands and observed results.
- **Outcome:** solved, partially solved, or unresolved.
- **Reusable lesson:** a concise generalizable takeaway.
- **Related notes:** links to relevant knowledge notes.
- **Training candidate:** no / pending review / approved.

A task record is not automatically a training example. Only promote it after checking correctness, privacy, licensing, and reproducibility.
